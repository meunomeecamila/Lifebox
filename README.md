## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/meunomeecamila/Lifebox.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd Lifebox
```

### 3. Run the project

Open `index.html` in your browser.

No additional installation or dependencies are required.
